One line: a home Wi-Fi router confessing why it dropped the connection at the exact moment a movie reached its climax. The joke turns the router from a dumb box into a fellow viewer — it saw the twist first, it panicked, and it took the whole connection down with it.

> I saw the killer's face before you did and I panicked. I dropped everything — including you.

## Run

```sh
node main.ts
```

Writes the entry line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` if set).
